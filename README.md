# Fake Job Detector 🔍

Fake Job Detector is an AI-assisted web application designed to help users identify suspicious job postings by analyzing job descriptions and detecting scam indicators.
It helps job seekers quickly evaluate whether a job opportunity appears genuine or risky before applying.

## ✨ Features

* Paste job description and analyze instantly
* Detect suspicious scam patterns
* Highlight risky phrases in job posts

## 🧠 How It Works

1. User pastes a job description
2. Frontend sends text for analysis
3. Scam indicators are detected
4. Risk score / warning shown to user

## 🚩 Scam Signals Checked

* Asking for money before joining
* Fake HR contact details
* Urgent joining pressure
* Unrealistic salary promises
* Suspicious email domains
